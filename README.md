# Brain Tumor Detection Using Deep Learning

## Overview

This project detects brain tumors from MRI images using Deep Learning and Transfer Learning with ResNet50V2.

## Features

- Brain MRI Classification
- Transfer Learning (ResNet50V2)
- TensorFlow/Keras
- Flask Web Application
- Image Upload
- Prediction Result

## Technologies

- Python
- TensorFlow
- Keras
- Flask
- OpenCV
- NumPy
- HTML
- CSS

## Dataset

Brain MRI Dataset (Training & Testing)

## Model

ResNet50V2

## Accuracy

Approximately 84–90% (depending on training).

## Future Improvements

- Better accuracy
- Explainable AI (Grad-CAM)
